# LoRa CLI

## Descripción
LoRa CLI es una interfaz de línea de comandos que actúa como gestor de dispositivos IoT (Internet of Things) basados en tecnología LoRa.

## Funcionalidades Principales
- Registro y gestión de nodos LoRa
- Registro y administración de Gateways
- Visualización y administración de paquetes de datos
- Integración con aplicaciones de terceros

## Objetivos
- Proporcionar un centro de administración centralizado para dispositivos IoT.
- Facilitar la integración con aplicaciones externas.
- Ofrecer herramientas para la visualización, monitoreo y gestión de paquetes de datos.
- Simplificar la administración de redes LoRa.
